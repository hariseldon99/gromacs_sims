## 1. Executive Summary

During analysis of protein–ligand interaction fingerprints using ProLIF and MDAnalysis, an unexpected `KekulizeException` (and subsequently `AtomValenceException: Explicit valence for atom # 41 C, 5, is greater than permitted`) occurred for the **CUEDC2–Ergotamine (`cuedc2_erg`)** complex. Further investigation revealed that the 2D interaction network displayed distorted, triangulated ring patterns (12 spurious 3-membered rings across aromatic and rigid systems).

A systematic audit across all 5 simulation directories (`cuedc2_rif`, `cuedc2_mid`, `cuedc2_par`, `cuedc2_dig`, and `cuedc2_erg`) was conducted to evaluate the protonation state and topology of each simulated ligand.

### Key Finding
* **`cuedc2_erg` (Ergotamine)** was the **only** system affected. It was parameterized with only polar hydrogens (`--AddPolarH`), omitting 32 non-polar hydrogens.
* **All other 4 simulations** (`cuedc2_rif`, `cuedc2_mid`, `cuedc2_par`, and `cuedc2_dig`) were prepared as **complete all-atom models** with 100% of expected hydrogens explicitly parameterized. Their trajectories remain physically sound and valid.

## 3. Root Cause Analysis: What Went Wrong in `cuedc2_erg`

### A. The `--AddPolarH` Flag in Step 1
In `cuedc2_erg/01_extract_and_prepare_ligand.py`, Step 4 invoked OpenBabel with `--AddPolarH`:
```python
ret = subprocess.run(
    [
        "obabel",
        "-ipdb", raw_pdb,
        "-opdb", "-O", prot_pdb,
        "--AddPolarH",  # <-- Root Cause
    ],
    capture_output=True, text=True
)
```
* **Why `--AddPolarH` exists:** Docking tools like AutoDock Vina use a **united-atom** representation where non-polar carbons absorb their hydrogens into unified spheres. Only polar hydrogens (on N, O, S) are explicitly modeled to compute hydrogen bonds.
* **Why it breaks MD:** AMBER/GAFF2 is an **all-atom** force field. When ACPYPE/Antechamber received `ERG.pdb` with only 46 atoms, Antechamber threw the following warning in `acpype.log`:
  ```text
  Warning: The assigned bond types may be wrong, please :
  (1) double check the structure (the connectivity) and/or 
  (2) adjust atom valence penalty parameters in APS.DAT...
  ```
  Antechamber forced un-hydrogenated carbons into unnatural hybridization states (e.g., assigning `c1` alkyne types to aliphatic carbons) to satisfy valence requirements without hydrogen atoms.

### B. Physical Consequences on the Simulation
1. **Severely Deflated van der Waals Volume**: In GAFF2, carbon Lennard-Jones parameters ($\sigma \approx 3.4\text{ \AA}$) rely on the surrounding explicit hydrogens ($\sigma \approx 2.5\text{ \AA}$) to establish steric exclusion. Without hydrogens, the ligand's effective volume was artificially shrunken, allowing water molecules and binding pocket residues to pack unnaturally close to the carbon skeleton.
2. **Distorted AM1-BCC Electrostatics**: Semi-empirical quantum mechanics (SQM) solved partial charges for a 46-atom system missing 32 nuclei and 32 valence electrons, skewing the dipole moment and electrostatic profile of the ligand.
3. **Missing Dihedral Terms**: Torsional barriers (H–C–C–H and H–C–C–C) were missing from `ERG_GMX.itp`, making the ergopeptine scaffold unnaturally flexible.

## 4. ProLIF Topological Artifacts Explained

### A. The Kekulization and Valence Exceptions
* **In Docked Pose (`complex_box.pdb`)**: Calling `plf.Molecule.from_mda(ligand_atoms)` failed with `KekulizeException: Can't kekulize mol. Unkekulized atoms: 25 30 31 32 33 34 35`. Because `implicit_hydrogens=False` by default in MDAnalysis, RDKit assumed any carbon without an explicit hydrogen had 0 hydrogens attached, making alternating single/double bond kekulization of the indole ring mathematically impossible.
* **In Equilibrated / Production Snapshots (`prod/start.pdb`, `prod/end.pdb`)**: Thermal vibrations caused interatomic distances to fluctuate. Calling `u.atoms.guess_bonds()` applied distance-based heuristics that placed **5 single bonds** on carbon atom # 41 (`C28`), triggering `AtomValenceException: Explicit valence for atom # 41 C, 5, is greater than permitted`.

### B. Spurious Triangular Rings
* A topological inspection of `ligand_mol` generated via `u.atoms.guess_bonds()` showed:
  ```python
  # Ring sizes produced by distance-based guess_bonds():
  [3, 3, 3, 3, 3, 3, 3, 3, 3, 3, 3, 4, 5, 5, 5, 5, 6, 6, 3]  # 12 spurious 3-membered rings!
  ```
* In reality, Ergotamine contains only 5- and 6-membered rings:
  ```python
  # True ring sizes (from reference chemical structure):
  [5, 5, 6, 6, 6, 5, 6, 6]  # 0 three-membered rings
  ```
* **Solution in ProLIF**: Call `guess_bonds()` only on `protein_atoms`, and load the ligand via `plf.Molecule.from_rdkit(ref_mol)` using coordinates mapped to the reference molecule.
